# Student Performance Prediction using Machine Learning

## Overview
This project predicts students' final exam grades (G3) using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Label Encoding
5. Train-Test Split
6. Linear Regression Model
7. Prediction
8. Model Evaluation

## Model Performance
- Mean Absolute Error (MAE): 1.49
- R² Score: 0.7546 (75.46%)

## Dataset
Student Performance Dataset (UCI/Kaggle)
